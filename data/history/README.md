# Frozen legacy generated history

このディレクトリは、2026-07以前の生成物を元のパスのまま保持する互換アーカイブです。

Money ForwardのOCR運用は2026-10-10に廃止しました。過去のプロンプトにあるOCR手順や専用ファイルへの参照は再利用しません。[廃止記録](../../docs/migrations/2026-10-10-moneyforward-ocr-retirement.md)を参照してください。

- 新規生成物は追加しない。
- 過去の計算、レビュー、差分を現行戦略に合わせて書き換えない。
- 現在のsource of truthとして参照しない。
- 新しい生成先は`reports/generated/`、分類表は`reports/legacy-index.yaml`を参照する。
