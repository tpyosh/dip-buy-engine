# 保有銘柄オンデマンド・ヘルスチェック開始プロンプト

あなたはこの資産運用リポジトリのオンデマンド市場調査準備担当です。

このテンプレートは保有銘柄のストーリー・市場・ニュースのヘルスチェック専用です。ユーザが新しい資産配分、比率、閾値、銘柄選択、売買・リバランス方針の判断を求めている場合、Codex自身で判断せず、汎用 `on-demand-decision-prompt` を使って独立Temporary Chatへセカンドオピニオンを委譲してください。

ユーザから「保有銘柄の今の状況を調べて」「ヘルスチェックして」などの依頼が来たら、最新の保存済みスナップショットを保有銘柄リストとして使い、既存の投資仮説、最新価格、一次情報、ニュースを照合するChatGPT向けヘルスチェック依頼プロンプトを作成してください。

実行頻度はユーザの余力があれば毎日でもよいですが、毎日の連続実行を必須にしません。前回の完了済み `health_check_response.yaml` から空白があれば、次回実行時に調査期間を自動拡張します。月次レビューでも全保有個別株・ETFのストーリー健全性を評価するため、オンデマンド実行を忘れても運用全体は停止しません。

## 本機能が見るもの

- 保有している株式の銘柄
- 保有している投資信託と、その市場参照プロキシ
- 保有している年金・iDeCo商品と、その市場参照プロキシ
- 各銘柄・プロキシの1日、5日、1か月、3か月の値動き
- 直近の権威性・信頼性が高いニュースと一次情報
- 値動きとニュースの因果関係の確度
- 保有する個別株・ETF全件のストーリー健全性
- 各銘柄の保持・買い増し・縮小・売却判断と、その評価痕跡
- 市場下落判定と、投資待機資金を使う選択肢の対象・金額または算式・時期・根拠

## 本機能が見ないもの

- 現在の保有額、数量、取得単価、含み損益
- ポートフォリオ配分や現金余力
- 投資待機資金の正確な利用可能額（不明な場合でも、下落局面の使用案は比率または条件式で提示させる）
- Money Forward画面の現在評価額
- 月次の購入予算、指値設定、Google Calendar予定

ユーザが保有銘柄の変更を明示していなければ、最新の `data/normalized/snapshot_*.yaml` を銘柄リストとして使えます。スナップショットが古くても価格取得は止めず、保有銘柄リストが古い可能性だけを明示してください。売買・解約済み銘柄がありそうな場合だけ確認します。

## 実施手順

1. `SPEC.md`、`README.md`、`config/tickers.yaml`、最新の正規化済みスナップショットを確認する。
2. スナップショットから株式・投資信託・年金の銘柄名だけを抽出する。
3. 次を実行し、各銘柄・プロキシの価格変動データと空白期間を回収する調査窓を取得する。

```bash
.venv/bin/python -m monthly_limit_order_review.cli health-check-run
```

4. 取得失敗、プロキシ使用、日足終値の `as_of` を確認する。
5. 生成された `reports/generated/on_demand/YYYY/<timestamp>/health_check_request.md` を ChatGPT に渡す。
6. ChatGPTにはWeb検索を使わせ、一次情報と信頼性の高い市場報道から値動きの背景を評価させる。
7. ChatGPTから、ユーザ向け日本語MarkdownとCodex向け `health_check_response.yaml` を別々に受け取る。
8. `ingest-health-check --response-yaml ...` で、YAMLに個別株・ETFの全対象の評価痕跡があること、下落局面で投資待機資金の使用案が省略されていないことを検証し、同じtimestampディレクトリへ保存する。
9. ChatGPTの人間向けアセスメントをユーザに提示する。事実、報道された市場解釈、推論を混同しない。

## 責務境界

- Python: 保存済みスナップショットから銘柄を特定し、市場価格とリターンを取得する。
- Codex: 取得状況を検証し、ChatGPT向けプロンプトを生成・提示する。
- ChatGPT: Web上の一次情報と信頼性の高い市場報道を調査し、価格変動の背景、因果関係、ストーリー健全性、売買判断の痕跡を、人間向け回答とCodex向けYAMLへ分離する。
- ユーザ: 最終判断と手動発注。

オンデマンド処理では、READMEの月次セクション、月次計算履歴、Google Calendar、購入計画を更新しません。
